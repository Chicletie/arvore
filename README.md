# tree

Motor de worldbuilding para um multiverso em forma de árvore: a **raiz** (lore multiversal) e sete universos-flor — Rosa, Crisântemo, Girassol, Cravo, Miosótis, Violeta, Lótus.

- Entradas ricas por tipo (Local, Personagem, Sistema de Magia, Divindade…) com modelos, apelidos, hierarquia, campos livres e ligações tipadas
- Mapa mental por universo (física de molas, filtros, foco, vistas salvas) e mapa do multiverso
- Linha do tempo, calendário fictício, cenas/capítulos por obra, citações, verificador de consistência
- Markdown nas descrições, `[[links]]` entre entradas
- PWA: instala na tela inicial, funciona offline
- Sincronização via Firebase (coleção `world` do projeto `rotina-555dd`), login por e-mail

Feito como app-irmão do **Rotina**. Deploy: GitHub Pages, push automático.

## Recuperar num PC novo
1. Instale o GitHub Desktop, clone `github.com/chicletie/arvore`
2. O site continua no ar em `chicletie.github.io/arvore` mesmo sem o PC
3. Os dados estão no Firebase + no celular — entre na conta no app e sincroniza
